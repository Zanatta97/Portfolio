Migrations do EF Core
Cria o script para alteração ou criação do banco de acordo com o model do banco de dados

Para utilizar existem duas formas:

1 - Pelo CMD
- Entrar na pasta do projeto
- dotnet ef // Valida se o EF Core está instalado corretamente
- dotnet ef migrations add 'nome' //Cria o script de migração
- dotnet ef migrations remove 'nome' //Apaga o script criado caso necessário
- dotnet ef database update //Roda o script e cria o banco ou atualiza as tabelas

2 - Pelo Package Manager Console
- Primeiro instalar o pacote NuGet Microsoft.EntityFrameworkCore.Tools
- No console do Package Manager Console
- - add-migration 'nome' //Cria o script de migração
- - remove-migration 'nome' //Apaga o script criado caso necessário
- - update-database //Roda o script e cria o banco ou atualiza as tabelas
